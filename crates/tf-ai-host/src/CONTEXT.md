# crates/tf-ai-host/src/

Up: [tf-ai-host/CONTEXT.md](../CONTEXT.md).

| File | What it does |
|---|---|
| `lib.rs` | Crate docs and the public API (re-exports from the modules below) |
| `vault.rs` | `CredentialVault`: one keychain entry for the API key. `production()` is service `com.typefaced.desktop`, account `openrouter-api-key` in Windows Credential Manager (`Local` persistence; `Unsupported` on other platforms). `set_key` accepts 1 to 512 visible ASCII characters; `has_key`, `delete_key` (no error when absent); `key()` is crate-private. Errors carry keyring's `Display` text only, never secret bytes. Tests use keyring-core's mock store, and on Windows a `com.typefaced.desktop.test` entry with a random account that a drop guard deletes |
| `policy.rs` | `ProxyRequest` (the IPC shape of a `fetch`) and `EgressPolicy`: only `POST https://openrouter.ai/api/v1/messages` (no user info, exact path after URL normalisation; query only `beta=true`); every other method, host and path is refused, `api.anthropic.com` included. Bodies up to 32 MiB, checked by `body.rs`, always sent as `application/json`. Passes only `anthropic-version`, `content-type` and `accept`, dropping every other header (`x-api-key`, `authorization`, `cookie` included); any `anthropic-beta` header is refused |
| `body.rs` | `check_body` for POST bodies: one JSON object with no duplicate key at any depth; only the top-level fields the client sends (`model`, `max_tokens`, `messages`, `system`, `tools`, `thinking`, `output_config`, `stream`, `fallbacks`), so OpenRouter's extensions (`plugins`, `provider`, `models`, `route`, …) are refused; a required model ID `anthropic/<model>` (lower case, at most 100 bytes, no `:variant` suffix, so no other vendor and no `openrouter/*` router) and at most 3 `fallbacks` of the form `{model}` with the same check; `max_tokens` at most 64000 and `thinking` absent or `{"type":"adaptive"}`; no top-level `mcp_servers`; no tool whose `type` is set and is not `"custom"` (server tools, `openrouter:*` included); no `source` key unless its value is a string (a citation) or an inline `base64`, `text` or `content` source (a `url` or `file` source would make the API fetch it). Returns the checked model for the ledger. Tested through `policy.rs` |
| `host.rs` | `EgressHost`: `fetch` checks the policy, adds `Authorization: Bearer <key>` from the vault (marked sensitive), sends with reqwest (no redirects, connect and read timeouts) and emits `ProxyEvent`s: `Head` (status, headers without `set-cookie`), UTF-8 `Chunk`s as they arrive, then `End`, `Error` or `Aborted`. At most 16 requests in flight; request IDs are 1 to 64 of `[A-Za-z0-9_-]`. `abort(request_id)` cancels an in-flight request, or one that has not registered yet (it is then never sent). Writes one ledger line per sent request |
| `ledger.rs` | `UsageLedger`: appends one JSON line per request (OpenRouter's `x-generation-id`, else `request-id`; the requested model; status, duration, byte counts) to a file; never bodies, headers or keys |
| `test_server.rs` | Test-only scripted HTTP/1.1 server on 127.0.0.1: records one request and answers with a chunked body whose parts can wait for the test, for the streaming and abort tests |

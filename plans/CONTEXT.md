# plans/

Construction plans, one per milestone (rolling-wave: the next milestone's plan is
written at the end of the current one). Up: [root CONTEXT.md](../CONTEXT.md).

| File | What it does |
|---|---|
| `typefaced-m1-headless-engine.md` | M1 blueprint. The status table at the top lists every step (`tf-model`, boolean adapter, command catalog, engine core, reducers, sandboxes, actor and journal, UFO/designspace/`.typefaced` I/O, incremental save, CLI, exit review), then parallel waves, M0 carry-over, scope fence, deviations, the user gates, and a self-contained brief per step |
| `typefaced-m0-foundations-and-spikes.md` | M0 blueprint. The status table at the top lists every step (bootstrap, skeleton, gates, CI, ADRs, fixtures, six technical spikes, exit review) with dependencies and status, followed by parallel waves, preflight findings and a self-contained brief per step |

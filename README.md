# Typefaced

A desktop app for creating and editing fonts. It has a guided Studio for beginners and a Workbench for professionals, with AI built in. It exports TrueType (static and variable), CFF-based OpenType and WOFF2. Windows comes first.

**Status:** planning and foundations (milestone M0). Not usable yet.

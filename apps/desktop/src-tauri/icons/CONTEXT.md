# apps/desktop/src-tauri/icons/

Application icons, placeholders from the Tauri template. `tauri.conf.json` → `bundle.icon`
lists the ones the bundler uses. Up: [src-tauri/CONTEXT.md](../CONTEXT.md).

| File | What it does |
|---|---|
| `32x32.png`, `128x128.png`, `128x128@2x.png` | PNG icons for the bundle and window |
| `icon.ico` | Windows icon (executable and installer) |
| `icon.icns` | macOS icon |
| `icon.png` | Large source icon |
| `Square30x30Logo.png` … `Square310x310Logo.png`, `StoreLogo.png` | Windows Store / MSIX tile logos (9 sizes + store logo) |

# packages/geometry-wasm/

Package `@typefaced/geometry-wasm`: `tf-geometry` compiled to WebAssembly. Its `pkg/`
folder is generated by `wasm-pack` from `crates/tf-wasm` and is not tracked; build it
before the frontend. Up: [packages/CONTEXT.md](../CONTEXT.md).

| File | What it does |
|---|---|
| `package.json` | Package manifest: exports `pkg/tf_wasm.js` and its types |
| `.gitignore` | Ignores the generated `pkg/` |
